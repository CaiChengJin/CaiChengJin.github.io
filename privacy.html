Privacy policy

Sales Knowledge Base
Operator: Justin Cai · Updated 1 November 2026

Purpose and scope

Sales Knowledge Base is a personal application for organizing the owner's sales reference documents. This policy describes the current document-processing application and this public information website.

Google user data accessed

With the owner's authorization, the processor accesses Drive file metadata and document contents in its configured source folder, including subfolders. Source material may include PDFs, Word files, images, text files and Google Docs. Metadata can include file IDs, names, MIME types, modification times, source links, sizes and content checksums.

The requested Google Drive OAuth scope can permit viewing, changing, creating and deleting all Drive files. The implemented processor restricts its operations to configured knowledge-base folders and does not implement deletion of original files. These implementation restrictions do not narrow the underlying OAuth scope.

How data is used

Documents are downloaded temporarily to a GitHub Actions runner for text extraction and OCR. Derived Markdown, hashes, source mappings, processing status, historical references and JSON indexes are written to the owner's configured Google Drive folders. Duplicate content is identified so existing extracted text can be reused.

Storage and recipients

Original and derived knowledge files remain in the owner's Google Drive. GitHub Actions temporarily processes document contents. OAuth refresh credentials are supplied through a GitHub Actions Secret, not repository source files. The local authorization helper can also save a credential JSON on the owner's own computer and, after confirmation, copy it to the local clipboard.

The application does not commit business documents, extraction outputs or tokens to its GitHub repository and does not upload these as Actions artifacts. Routine Actions output contains processing counts and error codes rather than document text. Google and GitHub process data under their respective services and terms.

Optional external AI processing

The configured provider is Alibaba Cloud Bailian, Beijing region, with model qwen3.7-plus on the standard pay-as-you-go API (free quota may offset usage). Only when the owner enables AI_ENABLED will extracted document text, up to 18,000 characters per request, be sent over HTTPS to this provider to generate review drafts. There is no automatic redaction of personal or confidential details. Source filenames and Drive IDs are attached locally to the result, rather than included in the model prompt. Up to five AI requests are attempted per workflow run. Generated drafts and their source relationships remain in private Google Drive pending human review.

Alibaba Cloud's privacy notice states that API data is not used for model training, and that model/application invocation data is stored as required by applicable rules. This is not a zero-retention service. Its current service agreement and account-specific settings apply; this application cannot delete provider-held records by deleting a Drive file. The owner should only add material they are authorized to share with these processing services. Other AI providers or subscription products require a fresh review of their practices.

Limited use

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. The operator does not sell Google user data, use it for advertising, or use it to train a generalized AI or machine-learning model.

Retention, deletion and access control

Generated files and historical indexes are retained until the owner removes them. Moving or deleting an original does not automatically delete previously extracted copies. To remove stored knowledge, the owner must delete the relevant original and derived files and any retained index/history entries in Drive. To stop future access, revoke the application's Google authorization, remove its GitHub Secret and disable the workflow. Locally saved credential files are controlled by the owner.

Google authorization can be reviewed or revoked in Google Account connections. Revoking authorization stops future authorized access but does not by itself delete previously generated Drive files.

Website information

This static information website has no document uploader, sign-in form, analytics script, advertising or application-managed cookies. Its hosting provider may process ordinary request and security logs. No private documents or credentials are published here.

Contact and changes

For privacy requests, contact Justin Cai using the support email shown on the Google consent screen. This policy will be updated when the application's enabled processing or recipients change.
