Personal document organization

Sales Knowledge Base

A personal application that turns sales reference documents into searchable, source-linked knowledge files stored in the owner's Google Drive.

What the application does

The owner selects a dedicated Drive folder for PDF files, Word documents, screenshots and notes. A Python process running in GitHub Actions extracts text and creates Markdown documents and a JSON source index in a separate knowledge folder.

Scheduled checks can process new or updated documents. Duplicate content is reused, previous output versions are retained, and source links are preserved. The processor does not delete original documents.

Google Drive access

The application requests Google Drive authorization so its unattended process can discover newly uploaded source documents and create derived files. The OAuth scope permits broad Drive access; the processor's folder configuration limits where its implemented operations run. This is a code-level restriction, not a folder-only OAuth permission.

The public website does not connect to Drive, collect credentials, or display the owner's documents. It provides application and privacy information only.

Human review and optional AI

AI-generated sales lessons, when enabled by the owner, are drafts for human review. They are kept separate from approved reference materials and are not automatically treated as company policy or commitments.

The configured optional AI provider is Alibaba Cloud Bailian in the Beijing region, using qwen3.7-plus through its standard API. AI processing starts only when the owner enables the workflow switch. Extracted document text is then sent to this provider for draft generation. See the privacy policy for data handling. No real customer data is published on this website.

Operator and intended use

Operated by Justin Cai for personal sales-reference organization. This is not a public sign-up service. For questions, use the owner's support email shown on the application's Google consent screen.
